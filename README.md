# SkyWatch ☁️🌞

Hey there! This is my third coding project ever! It's a weather app that tells you the weather in different cities. I built it for my Intro to Web Development Program, but I think it turned out pretty cool!

## What it does

- You can type in a city name and hit search
- It shows you the temperature, if it's sunny/rainy/etc
- Also tells you stuff like wind speed and humidity
- It looks pretty nice (at least I think so lol)

## How I made it

I used:
- HTML (the structure)
- CSS (to make it look nice)
- JavaScript (the cool stuff that makes it actually work)
- OpenWeather API (that's how it gets the actual weather data)

## How to use it

1. Download all the files
2. Get an API key from OpenWeather (it's free!)
3. Put your API key in the script.js file where it says 'YOUR_API_KEY'
4. Open index.html in your browser
5. Type a city name and hit search!
